# 参考资料

本目录存放英语口语陪练系统设计和开发过程中使用的参考项目。目录中的项目用于理解业务流程、模块边界、界面交互和工程实现方式，当前系统独立设计和开发。

| 目录 | 参考内容 |
| --- | --- |
| [`vault`](./vault/) | 后端模块职责、Agent 会话、知识检索、工具调用、语音交互和数据设计 |
| [`XE3-ESL`](./XE3-ESL/) | 英语学习产品的页面结构、练习流程、移动端与桌面端交互 |

参考项目只用于查阅和验证设计思路。当前服务的业务代码、数据模型、接口和部署配置放在项目根目录及其 `docs`、`cmd`、`internal` 等目录中，参考项目不参与当前服务的构建和运行。
