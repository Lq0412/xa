# 毕业设计需求说明

本文保留毕设原始题目要求，供核对交付要求使用；当前项目按 [路线图](ROADMAP.md) 开发。Flutter、语音及四类场景不作为当前已实现能力，是否恢复到交付范围需单独确认。

## 毕设题目描述

本课题面向英语学习者的自主口语训练需求，设计并实现基于大语言模型与语音交互的移动端英语口语陪练系统。系统采用 Flutter 构建 Android/iOS 客户端、Go 构建服务端、PostgreSQL 存储用户、会话和练习数据，接入大语言模型、语音识别和语音合成服务，实现用户登录、文字与语音多轮对话、流式回复、语音朗读，以及英文面试、IELTS 口语、职场英语、生活与旅行四类场景练习，并提供逐句纠错、评分反馈和历史复盘功能。

后端架构参考 [reference/vault](../reference/vault) 的模块划分和职责边界，前端 UI 与交互参考 [reference/XE3-ESL](../reference/XE3-ESL) 的页面结构和用户流程。两个项目仅用于理解业务和工程设计，当前系统独立开发。最终形成可运行的软件原型及需求分析、系统设计、接口设计和测试文档。

## 学生要求

要求学生具备计算机科学与技术专业基础，掌握程序设计、数据库、计算机网络和软件工程知识，能够使用 Flutter/Dart、Go 和 PostgreSQL 进行客户端、服务端及数据层开发，了解 REST、WebSocket、大语言模型 API、语音识别和语音合成服务的调用方法。

完成需求分析、系统设计、数据库与接口设计、核心功能开发和测试；打通“选择场景—文字/语音练习—反馈—历史复盘”完整流程，四类场景各完成至少一次端到端验证，并提交源代码、部署说明、测试报告和毕业论文。
